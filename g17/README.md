# Промышленное производство США по двум выпускам G.17

В каждой паре используется сезонно скорректированный общий индекс промышленного производства США, 2017 = 100. В ASCII-копиях откройте блок *Industrial Production and Capacity Utilization: Summary*, строку *Total index*, столбцы уровней *2017=100*. Метки `[p]` и `[r]` обозначают первую и пересмотренную оценки. Один пункт изменения уровня — разность индексов. В правой половине той же таблицы ФРС отдельно публикует темпы изменения в процентах.

A — первый опубликованный уровень прошлого месяца, B — его пересмотренный уровень в новом выпуске, C — первый уровень нового месяца. Изменение за месяц по текущей публикации равно C − B, пересмотр прошлого уровня равен B − A, изменение относительно ранее увиденного уровня равно C − A. Сравниваются числа в двух выпусках в том виде, в каком они напечатаны (один знак после запятой). Номера строк ниже считаются с единицы.

## Проверка

Из папки проекта запустите `python3 g17/verify_sources.py`. Скрипт автономно находит в обеих сохранённых публикациях заголовки и строку, сравнивает напечатанный в новом документе *Previous estimates* с предыдущим выпуском и проверяет все три числа по архиву оценок. В вычислениях используется десятичная арифметика. Результат сопоставляется с [cases.json](cases.json). Выпуски лежат в [releases](releases/). Создать cases.json заново можно командой `python3 g17/verify_sources.py --write`.

Хронология проверяется по сохранённому официальному календарю с учётом годовых пересмотров. В частности, для разработки не подошла пара 17 марта — 14 апреля 2023 года, поскольку 28 марта вышла отдельная годовая ревизия. Четыре включённые пары не имеют общих документов. Они отобраны по примерам смены знака и малых пересмотров, поэтому их соотношение не оценивает частоту таких ситуаций. [Календарь ФРС](https://www.federalreserve.gov/releases/g17/default.htm)

Отдельный официальный архив ФРС хранит четыре десятичных знака. Для каждого случая поля `archive_crosscheck.levels` в cases.json содержат A = init[t−1], B = rev1[t−1], C = init[t] для ряда B50001. Оба направления во всех четырёх примерах сохраняются с исходной точностью. В двух контрольных случаях пересмотры составляют +0,0140 и +0,0162 пункта и исчезают при округлении уровней до десятых. В архиве меняются база и методика во время годовых ревизий, поэтому сверяются база двух документов и отсутствие промежуточной публикации. Снимки источников сверены 22 ноября 2026 года.
