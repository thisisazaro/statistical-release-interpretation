# Два вопроса к двум последовательным выпускам

1. Как показатель изменился за последний месяц по текущей публикации?
2. Насколько последний опубликованный уровень отличается от уровня, который клиент видел в предыдущем выпуске?

A — последний уровень в предыдущем выпуске. B — оценка того же месяца в текущем выпуске. C — уровень нового месяца в текущем выпуске. Для каждой пары разность C − A равна сумме C − B и B − A. Направление относится к опубликованной точечной оценке. Сам по себе знак не устанавливает статистическую значимость движения.

Оба запроса получают один пакет из двух выпусков и трёх подписанных уровней. Для промышленного производства используем печатную точность индекса (2017 = 100, один десятичный знак), поэтому ответ измерен в пунктах индекса. Архив ФРС с четырьмя знаками даёт отдельную проверку округления. Нулевой печатный пересмотр может скрывать малую поправку. [Архив ФРС](https://www.federalreserve.gov/releases/g17/download.htm)

## Как читать контрольные случаи

На 3 парах знаки двух ответов совпадают. Одинаковое направление при разных величинах дают следующие данные — BLS за февраль 2025 г. Верный знак в таком случае сам по себе не доказывает, что система выбрала правильный период сравнения.
